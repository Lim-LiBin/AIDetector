# 🕵️‍♂️ On-Device 기반 AI 딥페이크 사칭 광고 판별 솔루션
유명인 사칭 투자 유도 불법 광고를 실시간으로 탐지하는 온디바이스 AI 모바일 플랫폼

## 📌 1. 프로젝트 개요

### 1.1 프로젝트 정의
본 프로젝트는 모바일 환경에서 별도의 외부 서버 전송 없이 생성형 AI 기반 가짜 콘텐츠를 실시간으로 식별하고 변조 영역을 시각화하는 안드로이드 온디바이스 AI 솔루션이다.

### 1.2 개발 배경
* **초실감형 가짜 콘텐츠의 확산:** 생성형 AI 기술의 급격한 발전으로 육안 식별이 불가능한 딥페이크가 급증하고 있다. 특히 유명인을 사칭한 SNS 투자 및 주식 사기 광고가 무분별하게 유포되어 심각한 금전적·사회적 피해를 야기한다.
* **기존 판별 시스템의 한계:** 대다수의 탐지 솔루션이 고사양 GPU 서버 기반의 웹 서비스로 제공된다. 이는 모바일 환경에서 접근성과 실시간성이 떨어지며, 사용자의 개인 이미지·영상이 외부 서버로 업로드되어 프라이버시 침해 우려가 존재한다.
* **솔루션의 필요성:** 모델 경량화 기술을 통해 스마트폰 내부에서 실시간으로 독립 구동 가능한 온디바이스 AI 시스템을 구축함으로써 프라이버시 보호와 즉각적인 접근성을 동시에 확보하고자 한다.

## ✨ 2. 주요 기능
* **하이브리드 입력 & 정밀 진단:** 카메라 즉시 촬영, 로컬 갤러리 파일 업로드뿐만 아니라 인스타그램·페이스북 등의 SNS URL 입력 방식을 지원한다. 별도의 캡처나 다운로드 절차 없이 링크 붙여넣기만으로 위변조 확률을 즉각 도출한다.
* **설명 가능한 AI(XAI) 히트맵 오버레이:** 합성으로 판단한 안면 영역의 미세 패턴을 분석하여 변조 의심 영역을 Grad-CAM 히트맵 형태로 원본 임미지 위에 반투명하게 시각화한다.
* **검사 리포트 및 이력 관리:** 분석 완료된 콘텐츠의 썸네일, 검사 일시, 확률 결과 데이터는 로컬 관리와 더불어 Firebase Firestore와 동기화되어 날짜별로 편리하게 조회할 수 있다.

### 3.3 AI 판별 파이프라인
모바일 기기의 자원을 효율적으로 사용하면서 정확도를 극대화하기 위해 다음과 같은 이원화 하이브리드 경로와 전처리 파이프라인을 구축한다.

1. **얼굴 검출 및 전처리:**
  * 이미지/영상 프레임 입력 시 `YuNet` 알고리즘을 구동하여 안면 좌표를 정밀 추출한다. (실패 시 Haar Cascade 방식으로 Fallback 처리)
  * 경계 픽셀의 부자연스러운 합성 흔적을 보존하기 위해 안면 윤곽 주변부에 20%의 여백(Padding)을 부여하여 크롭한 뒤 224x224 규격으로 리사이징 및 정규화를 진행한다.

2. **경량화 백본 모델 구동:**
   * 연산 효율성을 위해 **MobileNetV2** 아키텍처를 채택하고, 역잔차 블록(Inverted Residual Block)과 깊이별 분리 합성곱(Depthwise Separable Convolution)을 활용하여 파라미터 수를 최적화한다.
   * 안드로이드의 하드웨어 가속 인터페이스인 **NNAPI**(Neural Networks API)를 연동하여 기기 내 NPU 및 GPU 자원을 최대로 활용한다.
3. **이원화 추론 경로:**
   * **로컬 미디어 및 이미지 URL:** 외부 서버 전송 없이 기기 내부의 **TensorFlow Lite(TFLite)** 엔진으로 즉각 분석하여 프라이버시를 보장한다.
   * **SNS 영상 URL:** 분석 전용 백엔드 서버와 연동하여 스트리밍 데이터를 처리하고 고속 프레임 추출 과정을 거친 후 종합 판정한다.
4. **최종 분류 및 시각화:**
   * 전이학습으로 최적화된 이진 분류 계층(Binary Classifier)이 0~1 사이의 조작 확률을 출력하고 최적의 임계값(Threshold)에 따라 Real/Fake/Uncertain 상태를 반환한다.

## 📊 5. 정량적 성능 및 달성 결과
정상 이미지 100장과 AI 생성/변조 이미지 40장으로 구성된 내부 샘플 데이터셋을 통해 검증을 수행한 정량적 성능 결과 지표이다.

| 구분 | 목표 수치 | 결과 수치 | 달성 여부 | 비고 |
| :--- | :---: | :---: | :---: | :--- |
| **탐지율 (Recall)** | 85~90% 이상 | **87.5%** | **달성** | 조작 이미지 40장 중 35장 정탐지 완료 |
| **오탐지율 (FPR)** | 3% 이하 | **13%** | *개선 필요* | 정상 이미지 100장 중 13장 조작으로 오판 |
| **추론 속도 (Latency)** | 1.0초 이내 | **1.08초** | *부분 달성* | 단일 이미지 기준 순수 TFLite 모델 추론 시간 |
| **전체 분석 완료 시간** | 5.0초 이내 | **7.4초** | *개선 필요* | 얼굴 탐지, Grad-CAM 생성, Firebase 연동 시간 포함 |

## 🧠 7. 배운 점 및 트러블슈팅
* **모델 편향과 일반화:** 데이터 증강 단계에서 단순 복제를 배제하고 'class_weight' 분포 보정을 적용하여 모델 안정성을 확보했다. 진짜 사진의 디지털 노이즈나 압축 입자를 AI 합성 흔적으로 오인하는 편향을 발견했으며, 이를 해결하기 위해 JPEG 압축 주입, 가우시안 블러 등 도메인 맞춤 Argumentation의 중요성을 학습했다.
* **전처리 파이프라인 동기화:** 안면 인식 알고리즘('YuNet') 연동 시, 미세 오차를 줄이기 위해 안드로이드 비트맵 연산과 학습 환경의 Tensor 규격(20% 여백 패딩 및 224x224 리사이징)을 일치시키는 로직 동기화 능력을 배양했다.
* **로컬-서버 하이브리드 아키텍처 설계:** 비디오 스트리밍 프레임 처리를 위한 서버 파이프라인과 로컬 온디바이스 엔진 간의 트래픽을 효율적으로 분배하는 최적화 프로세스를 수립했다.

## ✅ 8. 향후 개선 사항
1. **UI/UX 디자인:** 현재 구현 완료된 탐지 엔진 및 백그라운드 아키텍처를 기반으로, 사용자 접근성과 시인성을 극대화하기 위한 선언형 UI 레이아웃 리팩토링 진행 예정
2. **FPR 오탐지율 최적화:** 진짜 사진 도메인에 대한 가우시안 노이즈 및 아티팩트 면역 강화 학습 알고리즘을 고도화하여 오탐지율을 목표치인 3% 미만으로 감소 조절
3. **멀티모달 탐지 확장:** 안면 합성 흔적 중심의 탐지를 넘어 사칭 유도 문구 텍스트 픽셀, 수익률 조작 차트 이미지 등 전체 맥락을 상호 교차 검증하는 복합 탐지 모델 적용 계획
